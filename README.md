smart_hotel_search **-** Интеллектуальный подбор отелей

Учебный командный проект по дисциплине «Технология командной разработки программ». Группа РИС-23-1Б, Пермский национальный исследовательский политехнический университет, 2026 г.

_Описание проекта_

smart_hotel_search - веб-сервис, который принимает от пользователя поисковый запрос на естественном русском языке, самостоятельно извлекает из него параметры поездки (город, даты заезда и выезда, число гостей, бюджет, индивидуальные пожелания) и возвращает готовую подборку вариантов проживания.

Для каждого найденного объекта сервис привлекает внешнюю языковую модель, которая анализирует массив отзывов гостей и формирует краткую выжимку: 2-3 ключевых преимущества и 1-2 недостатка. На основе соответствия отзывов критериям запроса система рассчитывает оценку релевантности (match score) и ранжирует варианты выдачи по убыванию соответствия.

_Назначение проекта_

Сервис предназначен для путешественников, желающих находить оптимальное жилье без многочасового ручного перебора фильтров на сайтах бронирования и чтения сотен разнородных отзывов. Пользователь формулирует запрос одной разговорной фразой, а система берет на себя рутину семантического анализа, отбора отелей и аналитики мнений постояльцев.
